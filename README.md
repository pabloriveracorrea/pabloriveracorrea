## About me

I am an **AI Solutions Builder** focused on turning practical needs into functional digital products. My strength is understanding a problem, defining how a solution should work, coordinating AI-assisted implementation, testing results and improving the product iteratively.

I work at the intersection of **business processes, technology and artificial intelligence**. I continue building my programming foundations while using modern development tools responsibly.

### What I bring to a project

- **Problem-solving:** translate real needs into actionable product requirements.
- **Business process understanding:** identify bottlenecks and opportunities for automation.
- **Functional design:** define modules, workflows, user roles, permissions and indicators.
- **AI-assisted development:** use programming assistants to accelerate implementation and review.
- **Product validation:** test releases, identify failures and prioritize fixes.
- **Continuous improvement:** evolve solutions with usability, security and maintainability in mind.

## How I build

<div align="center">

**DISCOVER → DESIGN → BUILD WITH AI → TEST → IMPROVE**

</div>

1. **Understand the need:** define the problem and desired outcome.
2. **Design the workflow:** document features, data flows and user requirements.
3. **Build with AI:** guide implementation through AI-assisted development tools.
4. **Test and validate:** verify functionality, investigate errors and review security.
5. **Improve:** iterate based on feedback and measurable results.

> AI speeds up development. Human judgment remains essential for requirements, quality, safety and release decisions.

### 02 — IPTV-PRC

**Android Digital Product · AI-Assisted Development**

An independent Android media-player project focused on adaptive navigation and playback across supported devices.

**Planned and developing capabilities:**

- Native Android app for phones and tablets.
- Android TV / Google TV adaptation.
- M3U and Xtream Codes source management.
- Live TV, movies and series navigation.
- Electronic program guide (EPG).
- Automated builds and APK testing.

**My role:** product concept, requirements, interface direction, AI-assisted implementation coordination, APK testing and issue prioritization.

**Technology:** Kotlin · Jetpack Compose · Media3 · Gradle · GitHub Actions

**Status:** Active development and compatibility testing.

*IPTV-PRC is an independent player. It does not provide media content, channels, playlists or IPTV subscriptions.*
